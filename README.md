# IDMLite - Fast and Easy Download Manager

IDMLite is an open-source desktop application that allows you to easily and quickly download videos, music, and files from the internet.

## Key Features

- Multi-connection downloading splits files into pieces for maximum download speed
- Resumes paused or broken downloads without data loss
- Single-click video capture and download from platforms like YouTube, TikTok, Instagram, and Twitter (X)
- Automatic download interception from web browsers directly to IDMLite
- User-friendly interface with light and dark theme options
- Lightweight, clean design that does not slow down your computer

## Installation

- Download IDMLite_Setup_v1.0.1.exe from the Releases section.
- Run the setup file and follow the on-screen instructions to complete the installation.

## Browser Extension Installation

The IDMLite browser extension is not hosted on any official web store (Chrome Web Store, Edge Add-ons, etc.). Follow these steps to install it manually:

- Open your browser extension management page (chrome://extensions for Chrome, edge://extensions for Edge).
- Enable "Developer mode" in the top-right corner.
- Click the "Load unpacked" button in the top-left area.
- Navigate to the program installation folder (default: C:\Program Files\IDMLite\extension) and select the "extension" folder.
- Once installed, the download button will appear automatically on pages with playable media.

# IDMLite - Hızlı ve Kolay Dosya İndirme Yöneticisi

IDMLite, internet üzerindeki video, müzik ve dosyaları bilgisayarınıza yüksek hızda ve kolayca indirmenizi sağlayan açık kaynaklı bir masaüstü uygulamasıdır.

## Temel Özellikler

- Çok parçalı indirme desteği sayesinde dosyaları parçalara bölerek maksimum hızda indirme
- Yarım kalan veya bağlantısı kopan indirmeleri veri kaybı olmadan kaldığı yerden devam ettirme
- YouTube, TikTok, Instagram, Twitter (X) gibi sitelerden tek tıkla video yakalama ve indirme
- Web tarayıcılarındaki normal indirmeleri otomatik yakalayıp IDMLite üzerinden başlatma
- Açık ve koyu tema seçenekleriyle gözü yormayan kullanıcı dostu arayüz
- Sistemi yormayan hafif ve sade çalışma yapısı

## Kurulum

- Sayfanın sağ tarafındaki Releases (Sürümler) bölümünden IDMLite_Setup_v1.0.1.exe dosyasını indirin.
- Kurulum dosyasını çalıştırıp ekrandaki yönergeleri takip ederek programı kurun.

## Tarayıcı Uzantısı Kurulumu

IDMLite tarayıcı uzantısı herhangi bir resmi web uzantı mağazasında (Chrome Web Mağazası vb.) yayınlanmamaktadır. Uzantıyı tarayıcınıza eklemek için aşağıdaki adımları uygulayın:

- Tarayıcınızın adres satırına chrome://extensions (Edge için edge://extensions) yazıp Enter tuşuna basın.
- Sayfanın sağ üst köşesinde bulunan "Geliştirici modu" seçeneğini açın.
- Sol üstte açılan "Paketlenmemiş öğe yükle" butonuna tıklayın.
- Programın kurulu olduğu dosya konumuna gidin (Varsayılan konum: C:\Program Files\IDMLite\extension) ve "extension" klasörünü seçin.
- Yükleme tamamlandıktan sonra video izlediğiniz sayfalarda indirme butonu otomatik olarak görünecektir.
